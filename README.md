# 🏘️ Sosyal Konut Tahsis Projesi

**Sosyal devlet anlayışıyla, dar gelirli aileler için yeni yaşam alanları.**

Sosyal Konut Tahsis Projesi; İstanbul genelinde sosyal konut tahsisine ilişkin proje bilgilerini, görsel materyalleri ve ilgili dokümanları kullanıcıların kolayca inceleyebilmesini amaçlayan bir web projesidir.

🔗 **Canlı Demo:** [sosyalkonuttahsisprojesi.vercel.app](https://sosyalkonuttahsisprojesi.vercel.app/)

📂 **GitHub Deposu:** [ekaraaslan/tahsisprojesi](https://github.com/ekaraaslan/tahsisprojesi)

---

## 📌 Proje Hakkında

Sosyal konut projeleri, barınma ihtiyacının karşılanması ve uygun yaşam alanlarına erişimin desteklenmesi açısından önem taşır.

Bu proje, Sosyal Konut Tahsis Projesi'ne ait içeriklerin web ortamında sunulmasını ve proje dokümanlarının dijital olarak incelenebilmesini hedefler.

## 🎯 Projenin Amacı

- Sosyal konut projesine ilişkin bilgileri dijital ortamda sunmak.
- Projeye ait görsel ve dokümanlara erişimi kolaylaştırmak.
- Proje tanıtımını anlaşılır ve erişilebilir bir web arayüzü üzerinden gerçekleştirmek.
- Sosyal konut tahsisine ilişkin içerikleri tek bir dijital ortamda bir araya getirmek.

## ✨ Proje İçeriği

Depoda bulunan dosyalara göre proje aşağıdaki materyalleri içermektedir:

- **HTML sayfaları:** Proje içeriğinin web üzerinden sunulmasını sağlayan sayfalar.
- **Görseller:** Projenin tanıtımında kullanılan görsel materyaller.
- **PDF dokümanları:** Projeye ilişkin teknik veya açıklayıcı dokümanlar.
- **Alternatif HTML sürümleri:** Farklı tasarım veya içerik düzenlemelerini içeren sayfalar.

## 🛠️ Kullanılan Teknolojiler

| Teknoloji / Araç | Kullanım amacı |
|---|---|
| HTML5 | Web sayfalarının yapısını oluşturmak |
| CSS3 | Sayfa tasarımını ve görsel düzeni sağlamak |
| JavaScript | İhtiyaç duyulan etkileşimleri gerçekleştirmek |
| Vercel | Projenin web ortamında yayınlanması |

*Not: Teknoloji listesi proje yapısına yönelik genel bir tanımdır. Kullanılan CSS ve JavaScript dosyalarının kapsamı kaynak kod incelenerek kesinleştirilmelidir.*

## 🚀 Kurulum ve Çalıştırma

Projeyi yerel bilgisayarınızda incelemek için aşağıdaki adımları uygulayabilirsiniz.

### 1. Depoyu klonlayın

```bash
git clone https://github.com/ekaraaslan/tahsisprojesi.git
```

### 2. Proje dizinine geçin

```bash
cd tahsisprojesi
```

### 3. Projeyi çalıştırın

Projenin HTML dosyalarından birini tarayıcıda açarak içeriği inceleyebilirsiniz.

Daha uygun bir yerel geliştirme ortamı için Visual Studio Code ve Live Server eklentisi kullanılabilir.

> Not: Projede özel bir derleme sistemi veya paket yöneticisi kullanılıyorsa çalıştırma adımları buna göre güncellenmelidir.
